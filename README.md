# 🥦 Fresh Vegetables Landing Page

A clean, modern, and fully responsive landing page designed for an organic fruits and vegetables market.

---

### 🛠️ Built With
* **HTML5:** Semantic markup structure
* **CSS3:** Modern styling, transitions, and effects
* **Flexbox:** Fluid and adaptive layout design
* **Media Queries:** Fully responsive for mobile, tablet, and desktop screens

---

### 🚀 Key Features
* 📱 **Mobile-First Responsive Design:** Optimized for all screen resolutions.
* ⚡ **Performance Optimized:** Clean code structure for fast loading times.
* 🎨 **Modern UI/UX:** User-friendly navigation and clear call-to-action sections.
